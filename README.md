# Customer Churn Analysis Project

---

## Introduction to Churn Analysis
In today’s competitive business environment, retaining customers is crucial for long-term success. Customer churn analysis is a key technique used to understand and reduce customer attrition.

It involves analyzing customer data to identify patterns and reasons behind customer departures. By using data analytics and machine learning, businesses can predict which customers are at risk of leaving and take proactive actions to improve retention.
This project demonstrates how data can be transformed into actionable insights for business decision-making.

---

## Project Objective
The main objectives of this project are:
- Analyze customer churn behavior in a telecom company
- Identify key factors influencing customer churn
- Build an interactive dashboard for business insights
- Develop a machine learning model to predict future churners

---

## Dataset Description
The dataset used in this project represents telecom customer data and includes:

- Customer demographics (age, gender, marital status, state)
- Subscription details (contract type, tenure, services used)
- Billing information (monthly charges, total charges, payment method)
- Target variable: Customer Status (Stayed / Churned / Joined)

---

## Project Target
This project aims to:
- Build an end-to-end ETL process in a database
- Develop a Power BI dashboard for analysis
- Study customer churn patterns
- Identify areas for marketing improvements
- Predict future churners using machine learning

## Project Workflow

### 1. Data Cleaning (SQL)
- Created staging and production tables
- Handled missing values using ISNULL
- Prepared structured data for analysis

### 2. Exploratory Data Analysis (Power BI)
- Built interactive dashboards to analyze churn patterns
- Studied customer behavior across:
  - Demographics
  - Geography
  - Payment methods
  - Contract types
  - Services used

### 3. Dashboard Development
Created an executive dashboard to track:
- Total customers
- Churn rate
- New joiners
- Customer segmentation insights

### 4. Machine Learning Model
- Used Random Forest Classifier
- Encoded categorical variables
- Split data into training and testing sets
- Evaluated model performance

---

## Key Insights
- Month-to-month customers have the highest churn rate
- Higher monthly charges increase likelihood of churn
- Customers with longer tenure are more loyal
- Lack of additional services increases churn risk

---

## Machine Learning Insight
A Random Forest model was used to classify customers as:
- Likely to stay
- Likely to churn

This helps businesses take proactive retention actions such as:
- Discounts and offers
- Improved customer support
- Personalized engagement strategies
